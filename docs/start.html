Connect your steps

once, 3 min
❤️iPhone
Apple Health→Shortcuts app→Effort
Build one Shortcut + a few daily automations. Syncs at 1pm, 6:50pm (before the Taxman) and 11:50pm by itself. The app's Sync now button runs it any time.
💚Android
Google Fit / Samsung Health / Fitbit→Health Connect→HC Webhook→Effort
Install HC Webhook (free) → allow Steps → paste your link. Syncs every 30 min. Set its battery to Unrestricted.
✍️No setup
Type them in from Me → Steps. Works, but you have to remember before 7pm.
The app walks you through it with your own links already filled in. Just copy and paste.
